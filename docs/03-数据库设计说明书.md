# 智慧交通综合管理服务平台 —— 数据库设计说明书

> 版本：1.0　|　日期：2026-09-20
> 库名：`smart_traffic`（utf8mb4_general_ci）；建表脚本 `sql/init.sql`；种子数据 `sql/seed.sql`（由 `scripts/gen_seed.py` 生成）
> 全局约定：所有表含 `id`（自增主键）、`created_at`、`updated_at`；软删除字段 `is_deleted`（1=已删）；时间字段一律 `DATETIME`（Asia/Shanghai 本地时间）；表间为逻辑外键，应用层保证一致性。

## 2. 用户与权限

### 2.1 user（用户表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK, 自增 | 用户 ID |
| username | VARCHAR(64) | UNIQUE, NOT NULL | 登录名 |
| password_hash | VARCHAR(128) | NOT NULL | bcrypt 哈希（钉死 bcrypt 4.0.1） |
| real_name | VARCHAR(64) | DEFAULT '' | 姓名 |
| phone | VARCHAR(20) | DEFAULT '' | 手机号 |
| email | VARCHAR(128) | DEFAULT '' | 邮箱 |
| status | TINYINT | DEFAULT 1 | 1 启用 / 0 禁用 |
| is_deleted | TINYINT | DEFAULT 0 | 软删除 |
| created_at / updated_at | DATETIME | 自动维护 | 创建/更新时间 |

### 2.2 role（角色表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK, 自增 | 角色 ID |
| code | VARCHAR(32) | UNIQUE | 角色编码：admin / officer / user |
| name | VARCHAR(64) | NOT NULL | 角色名称 |
| description | VARCHAR(255) | DEFAULT '' | 描述 |

### 2.3 menu（菜单表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK, 自增 | 菜单 ID（种子固定 1-25） |
| parent_id | INT | DEFAULT 0 | 父菜单，0=顶级 |
| name | VARCHAR(64) | NOT NULL | 菜单名称 |
| path | VARCHAR(128) | DEFAULT '' | 前端路由路径 |
| component | VARCHAR(128) | DEFAULT '' | 前端组件路径 |
| icon | VARCHAR(64) | DEFAULT '' | Element Plus 图标名 |
| menu_type | TINYINT | DEFAULT 1 | 1 菜单 / 0 目录 |
| sort_order | INT | DEFAULT 0 | 排序号 |
| visible | TINYINT | DEFAULT 1 | 1 显示 / 0 隐藏 |

### 2.4 user_role（用户-角色关联）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| user_id | INT | NOT NULL, UNIQUE(user_id, role_id) | 用户 |
| role_id | INT | NOT NULL | 角色 |

### 2.5 role_menu（角色-菜单关联）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| role_id | INT | NOT NULL, UNIQUE(role_id, menu_id) | 角色 |
| menu_id | INT | NOT NULL | 菜单 |

### 2.6 op_log（操作日志表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| user_id | INT | NULL | 操作人（可空） |
| username | VARCHAR(64) | DEFAULT '' | 冗余用户名 |
| action | VARCHAR(64) | NOT NULL | 操作类型：登录/新增/修改/删除/审核/发布/受理/录入/上报/识别/入场/出场/计算 等 |
| detail | VARCHAR(512) | DEFAULT '' | 详情 |
| ip | VARCHAR(64) | DEFAULT '' | 来源 IP |

索引：`idx_log_created(created_at)`、`idx_log_user(user_id)`。

## 3. 路口与信号

### 3.1 intersection（路口表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | 路口 ID（种子 1-8 固定） |
| name | VARCHAR(64) | NOT NULL | 名称（中山路口等） |
| longitude | DECIMAL(10,6) | NOT NULL | 经度（模拟路网坐标） |
| latitude | DECIMAL(10,6) | NOT NULL | 纬度 |
| lane_count | INT | DEFAULT 4 | 车道数 |
| district | VARCHAR(64) | DEFAULT '' | 辖区（城东/城西/城南/城北） |
| status | TINYINT | DEFAULT 1 | 1 启用 / 0 停用 |

索引：`idx_intersection_district(district)`。

### 3.2 signal_plan（信号配时方案表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| intersection_id | INT | NOT NULL | 所属路口 |
| name | VARCHAR(64) | NOT NULL | 方案名称 |
| mode | VARCHAR(16) | DEFAULT 'fixed' | fixed=定周期 / adaptive=感应自适应 |
| cycle_seconds | INT | DEFAULT 90 | 周期时长（秒），钳制 [40,180] |
| phase_count | INT | DEFAULT 4 | 相位数 |
| phases | JSON | NULL | `[{name, green, yellow, allRed}, ...]` |
| green_ratio | DECIMAL(5,4) | DEFAULT 0.4 | 绿信比 = Σ绿灯/周期 |
| is_active | TINYINT | DEFAULT 0 | 1=当前启用（同路口唯一） |
| created_by | INT | NULL | 创建人 |

索引：`idx_plan_intersection(intersection_id)`。

### 3.3 signal_status（信号灯实时状态表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| intersection_id | INT | UNIQUE | 一路口一行 |
| current_phase | VARCHAR(64) | DEFAULT '' | 当前相位名 |
| remaining_seconds | INT | DEFAULT 0 | 剩余秒数（模拟任务每 10s 递减） |
| mode | VARCHAR(16) | DEFAULT 'fixed' | 当前模式 |
| cycle_seconds | INT | DEFAULT 90 | 当前周期 |

### 3.4 road_section（路段表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| name | VARCHAR(64) | NOT NULL | 路段名称 |
| start_intersection_id | INT | NOT NULL | 起点路口 |
| end_intersection_id | INT | NOT NULL | 终点路口 |
| lane_count | INT | DEFAULT 4 | 车道数 |
| length_km | DECIMAL(6,2) | DEFAULT 1.00 | 长度（公里） |
| direction | VARCHAR(16) | DEFAULT '东西' | 走向：东西/南北 |
| capacity | INT | DEFAULT 2400 | 通行能力 = 车道数 × 600 pcu/h |

### 3.5 traffic_flow（交通流量表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 数据量大，用 BIGINT |
| road_section_id | INT | NOT NULL | 路段 |
| recorded_at | DATETIME | NOT NULL | 记录时间（小时行 HH:00:00 / 分钟行秒级） |
| flow | INT | DEFAULT 0 | 折算小时流率 pcu/h（分钟行 = 该分钟辆数 × 60） |
| speed | DECIMAL(6,2) | DEFAULT 0 | 平均车速 km/h |
| saturation | DECIMAL(5,3) | DEFAULT 0 | 饱和度 v/c（flow/capacity，封顶 1.2） |
| congestion_level | TINYINT | DEFAULT 0 | 0 自由流 / 1 缓行 / 2 拥堵 / 3 严重拥堵（阈值 0.4/0.7/0.9） |

索引：`idx_flow_section_time(road_section_id, recorded_at)`、`idx_flow_time(recorded_at)`——支撑按路段/时间范围聚合（按天索引设计，30 天种子 1.4 万行）。

种子形态（附录 D.3）：平峰基线 300–600、早晚高峰（7:30–9:00 / 17:30–19:00）峰值 1500–2200、夜间 50–150、±10% 噪声、周五晚高峰 ×1.15、周末高峰 ×0.6。

## 4. 车辆与违章

### 4.1 vehicle（车辆表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| user_id | INT | NULL | 登记用户（普通用户本人车辆，空=系统登记） |
| plate_no | VARCHAR(16) | UNIQUE | 车牌号（普通 7 位 / 新能源 8 位） |
| vehicle_type | VARCHAR(32) | DEFAULT '小型汽车' | 车辆类型 |
| color | VARCHAR(16) | DEFAULT '' | 车身颜色 |
| owner_name | VARCHAR(64) | DEFAULT '' | 车主姓名 |
| owner_phone | VARCHAR(20) | DEFAULT '' | 联系电话 |

### 4.2 violation（违章表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| vehicle_id | INT | NULL | 关联车辆（可空） |
| plate_no | VARCHAR(16) | NOT NULL | 车牌号（冗余，便于按牌查询） |
| intersection_id | INT | NULL | 违章地点（路口） |
| violation_type | VARCHAR(32) | NOT NULL | 闯红灯/超速/违停/不按导向车道行驶 |
| violation_time | DATETIME | NOT NULL | 违章时间 |
| fine_amount | DECIMAL(8,2) | DEFAULT 0 | 罚款金额 |
| deduct_points | INT | DEFAULT 0 | 记分 |
| status | VARCHAR(16) | DEFAULT 'pending' | pending 待审核 → confirmed 已确认 / rejected 已驳回 → processed 已处理 |
| evidence_url | VARCHAR(255) | DEFAULT '' | 取证照片（/static/uploads 相对路径） |
| audit_by | INT | NULL | 审核人 |
| audit_remark | VARCHAR(255) | DEFAULT '' | 审核备注 |
| audit_time | DATETIME | NULL | 审核时间 |
| remark | VARCHAR(255) | DEFAULT '' | 备注 |

索引：`idx_violation_plate`、`idx_violation_time`、`idx_violation_status`。

## 5. 智慧停车

### 5.1 fee_rule（计费规则表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| name | VARCHAR(64) | NOT NULL | 规则名称 |
| free_minutes | INT | DEFAULT 15 | 免费时长（分钟） |
| first_hour_fee | DECIMAL(8,2) | DEFAULT 5.00 | 首小时费用（元） |
| hourly_fee | DECIMAL(8,2) | DEFAULT 3.00 | 之后每小时（不足 1 小时按 1 小时） |
| daily_cap | DECIMAL(8,2) | DEFAULT 40.00 | 单日封顶（每满 24 小时按一段另计） |

计费示例（免费 15 分、首小时 5、每小时 3、封顶 40）：停 65 分钟 → 5 元；停 76 分钟 → 8 元；停 10 小时 → 32 元；停 20 小时 → 40 元（封顶）；停 2 天 1 小时 → 85 元。

### 5.2 parking_lot（停车场表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| name | VARCHAR(64) | NOT NULL | 名称 |
| address | VARCHAR(255) | DEFAULT '' | 地址 |
| total_slots | INT | DEFAULT 100 | 车位总数 |
| used_slots | INT | DEFAULT 0 | 当前占用 |
| fee_rule_id | INT | NULL | 套用计费规则 |

### 5.3 parking_record（出入场记录表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | PK | — |
| parking_lot_id | INT | NOT NULL | 停车场 |
| plate_no | VARCHAR(16) | NOT NULL | 车牌号 |
| enter_time | DATETIME | NOT NULL | 入场时间 |
| exit_time | DATETIME | NULL | 出场时间（空=在场） |
| fee | DECIMAL(8,2) | NULL | 结算费用 |
| status | VARCHAR(16) | DEFAULT 'inside' | inside 在场 / finished 已出场 |
| image_url | VARCHAR(255) | DEFAULT '' | 入场拍照（/static/uploads 相对路径） |

索引：`idx_record_plate`、`idx_record_enter`、`idx_record_lot_status(parking_lot_id, status)`（重复入场与在场查询热点路径）。
