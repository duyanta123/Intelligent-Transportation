## 4. 缺陷记录与修复

| 编号 | 现象 | 根因 | 修复 | 验证 |
|---|---|---|---|---|
| BUG-01 | 全量 pytest 时间歇性失败：history 聚合 total=0 | MySQL DATETIME 对小数秒**四舍五入**（20.6s 存为 21s），查询端 `end=now()` 早于入库值，秒边界竞态 | history 查询 end 预留 1 秒缓冲 | 连续 3 轮全量回归通过 |
| BUG-02 | 同秒内两次登录的 token 完全相同，登出黑名单误伤后续登录 | JWT iat 秒级精度导致载荷相同 | payload 增加唯一 `jti` | test_auth 全绿 |
| BUG-03 | 登录第 5 次失败仍返回 401（第 6 次才 429） | 锁定写入后本次仍走原分支 | 计数达 5 时直接抛锁定异常 | TC-B07 通过 |
| BUG-04 | 大屏地图空白 | 地图容器 `height:100%` 在 flex 布局解析为 0 | 固定像素高度 545px | 浏览器复测正常 |
| BUG-05 | 车牌识别始终走降级 | HyperLPR3 返回格式为 `[车牌,置信度,类型,框]`，解析按 8 元素格式过滤 | 修正解析取 item[0]/item[1] | 合成车牌图识别 96.5% 置信度 |
| BUG-06 | 首次调用识别接口超时 | 模型（约 12MB）在首个请求内同步下载+初始化 >10s | 启动时后台预热模型，请求侧等待+超时保护，失败可重试 | 重启后首请求即成功 |
