# 智慧交通综合管理服务平台 —— 部署与用户手册

> 版本：1.0　|　日期：2026-09-20　|　适用环境：Windows 10/11 x64（其他平台命令按需替换）

## 1. 从零开始部署

### 1.1 环境要求

| 软件 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 20.19（实测 22.21.0） | 前端构建与开发 |
| Python | 3.13.x（实测 3.13.9） | 后端运行 |
| MySQL | 8.0（Windows 服务 `MySQL80`） | 业务库；需已知 root 密码 |
| Redis | 5.0.14（Windows 服务 `Redis`） | 缓存；只用 5.x 支持的命令 |

> 无需 Docker。MySQL/Redis 客户端不在 PATH 时请使用完整路径（见 1.4）。

### 1.2 初始化后端

```bash
cd smart-traffic/backend

# 1) 创建虚拟环境
python -m venv venv
source venv/Scripts/activate        # Git Bash；PowerShell 用 .\venv\Scripts\Activate.ps1

# 2) pip 使用清华镜像（可选，加速）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 3) 安装依赖（requirements.txt 已锁定版本）
pip install -r requirements.txt
```

### 1.3 配置 `.env`

复制模板并填写真实值（**真实 `.env` 不入库**）：

```bash
cp .env.example .env
```

```dotenv
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=smart_traffic
DB_USER=root
DB_PASSWORD=你的MySQL密码          # 必填
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_DB=0
JWT_SECRET=随机32位以上字符串       # 必填（可用 python -c "import secrets;print(secrets.token_urlsafe(48))" 生成）
JWT_EXPIRE_MINUTES=120
MOCK_DATA_ENABLED=true             # 答辩演示数据模拟开关
CAPTCHA_TTL_SECONDS=300
DASHBOARD_CACHE_TTL_SECONDS=8
UPLOAD_DIR=uploads
```

前端环境（已内置）：`frontend/.env` → `VITE_API_BASE=/api/v1`。

### 1.4 初始化数据库

```bash
# 客户端完整路径示例（若已加入 PATH 可直接用 mysql）
MYSQL="C:/Program Files/MySQL/MySQL Server 8.0/bin/mysql.exe"

"$MYSQL" -uroot -p < sql/init.sql        # 建库 smart_traffic + 18 张表
"$MYSQL" -uroot -p smart_traffic < sql/seed.sql   # 种子数据（约 1.5MB，含 30 天流量/520 违章/300 出入场）
```

或直接使用一键脚本 `reset-db.bat`（见第 4 节）。

### 1.5 启动服务

```bash
# 后端（端口 8000，接口文档 /docs）
cd backend
./venv/Scripts/python.exe -m uvicorn app.main:app --reload --port 8000

# 前端（端口 5173）
cd frontend
npm install        # 首次
npm run dev
```

一键启动见 `start.bat`。浏览器访问 **http://localhost:5173**。

### 1.6 VS Code 打开与调试

1. 用 VS Code 打开 `smart-traffic/` 文件夹；
2. 安装扩展：Python、Vue - Official（Volar）、ESLint；
3. 后端调试：创建 `.vscode/launch.json`：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "FastAPI 后端调试",
      "type": "debugpy",
      "request": "launch",
      "module": "uvicorn",
      "args": ["app.main:app", "--reload", "--port", "8000"],
      "cwd": "${workspaceFolder}/backend",
      "python": "${workspaceFolder}/backend/venv/Scripts/python.exe",
      "env": {"TESTING": "0"}
    }
  ]
}
```

4. 前端调试：终端运行 `npm run dev`；如需浏览器断点调试，可安装「Chrome Debugger」或使用 Edge DevTools 协议；
5. 推荐工作区设置：保存时自动格式化（ruff + eslint）。

### 2.1 管理员（admin）操作指引

1. **系统仪表盘**：查看用户/车辆统计、近 7 天流量、违章分布、最近操作日志；
2. **系统管理**：用户管理（启用/禁用/编辑）、角色管理、菜单管理（树形 CRUD）、操作日志检索；
3. **交通管理**：路口管理（增删改查 8 个种子路口）→「配时计算」直达配时页；
4. **信号配时**：左侧输入各相位流量与车道数 →「计算最优周期」查看 Webster 结果 → 可保存为方案；右侧方案列表可启用/删除方案（同路口仅一个启用）；
5. **路况监测**：路段管理维护路段；「流量与拥堵」页查看实时拥堵、历史趋势（小时/天聚合），或手动「模拟上报」；
6. **车辆违章**：车辆登记（支持新能源 8 位牌）、违章录入（自动带出罚款/记分预设）、审核通过/驳回、标记已处理；
7. **智慧停车**：停车场管理、计费规则（免费时长/首小时/每小时/封顶）、出入场记录页可「车辆入场」（可传入场拍照）与「车辆出场结算」；
8. **智能工具 → 车牌识别**：上传车辆图片识别车牌，一键复制填入出入场/违章表单；识别失败时按提示手动录入；
9. **公共服务**：公告发布/管理；投诉反馈查看与受理。

### 2.2 交警/运营（officer）操作指引

- 可查看交通管理与路况全部页面，进行**配时计算**、**流量上报**；
- 可**录入违章**并**审核**；可办理车辆**出入场**；
- 受理处理投诉反馈；查看公告；
- 无系统管理权限（菜单自动隐藏，后端接口同样 403 兜底）。

### 2.3 普通用户（user）操作指引

- **数据可视化大屏**：全屏查看全市交通态势（数据 10 秒自动刷新）；
- **路况监测**：查看路段与流量/拥堵（只读）；
- **车辆违章**：仅能查询本人登记车辆与对应违章；
- **智慧停车**：查看各停车场剩余车位；
- **公共服务**：浏览公告、提交投诉反馈并跟踪本人工单处理进度。

## 3. 常见问题（FAQ）

**Q1：启动后端报 `Access denied for user 'root'`？**
`.env` 中 `DB_PASSWORD` 未填或填错；确认 MySQL 服务（MySQL80）正在运行。

**Q2：后端启动报 Redis `unknown command HELLO`？**
Redis 服务版本低于 6；本项目已强制 RESP2 协议连接，请确认连接的是本机 Redis 5 服务（不要指向其他项目的 Redis 云实例）。

**Q3：登录提示「验证码错误或已过期」？**
验证码 5 分钟有效且一次性使用；点击图片刷新后重新输入。多个项目共用同一 Redis 时，建议为本项目分配独立 `REDIS_DB`。

**Q4：车牌识别一直失败？**
首次运行会在启动时后台下载模型（约 12MB），网络受限时下载失败会走「手动录入」降级。检查网络后重启后端（或再次调用识别接口触发重试）。确认依赖 `hyperlpr3==0.1.3` 已安装。

**Q5：大屏数据不刷新/显示「后端服务连接失败」？**
后端 8000 端口未启动或跨域被拦截；点击「重新连接」，或重启后端后刷新页面（10 秒轮询会自动恢复）。

**Q6：演示数据被测试弄脏了怎么办？**
运行 `reset-db.bat` 一键还原种子数据（见下节）。

**Q7：想关闭每分钟的模拟流量上报（答辩时使用真实数据）？**
将 `backend/.env` 中 `MOCK_DATA_ENABLED=false` 后重启后端。

**Q8：上传图片 413/400？**
仅支持 jpg/jpeg/png/webp 且不超过 5MB。

## 4. 一键脚本

| 脚本 | 用途 |
|---|---|
| `start.bat` | 同时拉起后端（8000）与前端（5173），自动打开浏览器 |
| `stop.bat` | 停止本项目占用 8000/5173 端口的进程 |
| `reset-db.bat` | 从 `backend\.env` 读取连接参数，重新导入 `sql/init.sql + seed.sql` 还原演示数据（执行前二次确认） |

> `.bat` 均为 CRLF + UTF-8 BOM 编码，双击即可运行。

## 5. 生产部署提示（课程加分阅读）

1. 前端构建产物 `npm run build` → `dist/`，可由 Nginx 托管并将 `/api` 反代到 8000 端口；
2. 后端生产环境建议 `uvicorn app.main:app --workers 2`（去掉 `--reload`）；
3. `JWT_SECRET` 必须更换为强随机值；数据库账号遵循最小权限；
4. 定期备份 `backend/uploads/` 与数据库（`mysqldump smart_traffic`）。
