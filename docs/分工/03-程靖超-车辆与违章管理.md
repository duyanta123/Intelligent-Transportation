## 1. 第 1 周：需求与设计

### 1.1 业务规则确认

- **违章类型字典（在 `violation.py` 中硬编码，不落库）**：

| code | 罚款 | 扣分 |
|---|---|---|
| 闯红灯 | 200 | 6 |
| 超速 | 200 | 3 |
| 违停 | 150 | 0 |
| 不按导向车道行驶 | 100 | 2 |

- **状态机**：`pending（待审核）→ confirmed（已确认）/ rejected（已驳回）`；`confirmed → processed（已处理）`；`rejected/pending` 不允许直接 `processed`；已审核的不允许再审核（20003）。
- **权限**：admin 可增删改查 + 审核 + 处理；officer 可录入、审核、处理，不可删车辆（DELETE /vehicles/{id} 限 admin）；user 只能看自己名下车辆及对应违章。
- **车牌规则**：普通 7 位（省 + 字母 + 5 位）、新能源 8 位（省 + 字母 + 6 位，第六位字母 D/F）；统一 `normalize_plate` 去空格转大写后再校验。
- **软删车牌复用**：删除车辆时 `plate_no` 改写为 `*{id}`（墓碑），原车牌可重新登记；新建/修改都要查重并接 IntegrityError 兜底 → 20005。

### 1.2 表字段设计

**vehicle（车辆表）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK AI | 主键 |
| user_id | INT NULL | 登记用户 id（user 角色据此过滤） |
| plate_no | VARCHAR(16) UK | 车牌号（唯一索引） |
| vehicle_type | VARCHAR(32) | 小型汽车/大型汽车/新能源… |
| color | VARCHAR(16) | 车身颜色 |
| owner_name | VARCHAR(64) | 车主姓名 |
| owner_phone | VARCHAR(20) | 联系电话 |
| created_at / updated_at / is_deleted | - | 审计字段 |

**violation（违章表）**：id、vehicle_id（可空）、plate_no、intersection_id（可空，关联郭佳豪的路口）、violation_type、violation_time、fine_amount（Numeric(8,2)）、deduct_points、status（pending/confirmed/rejected/processed）、evidence_url、audit_by、audit_remark、audit_time、remark + 审计字段

## 2. 第 2 周：公共校验函数（utils/validators.py 我负责的两个）

### 2.1 `is_valid_plate(plate: str) -> bool`

- 正则口径（`validators.py` 唯一实现）：`^[省份简称][A-HJ-NP-Z][A-HJ-NP-Z0-9]{4,6}$` —— 省份 31 个简称 + 发牌机关字母（不含 I/O）+ **4~6 位**尾号，一个正则同时覆盖普通 7 位与新能源 8 位；`is_valid_plate` 内部先 `strip().upper()` 再匹配
- 新能源 8 位（如 京AD12345）与普通 7 位走同一正则，不做 D/F 特判（靠车型字典与人工核对兜底）；**前端与后端同源**：`frontend/tests/login.spec.ts` 与 `views/vehicle/vehicles.vue` 使用与后端完全相同的字符类 `[京津沪渝冀晋辽吉黑苏浙皖闽赣鲁豫鄂湘粤桂琼川贵云陕甘青蒙藏宁新][A-HJ-NP-Z][A-HJ-NP-Z0-9]{4,6}`
- 单测锚点：`test_normal_plates`（京A12345 / 冀B6F888）、`test_new_energy_plates`（京AD12345 / 京AF8888）、`test_invalid_plates`（BAD123 / 京AI2345 / 京A123 / 空串）、`test_normalize_uppercases`（" jina12345 " 与 京a12345→京A12345）
- 验收：`京A12345` ✓、`鲁A12345` ✓、`京AD12345` ✓（新能源）、`ABC123` ✗、`京A1234` ✗

### 2.2 `normalize_plate(plate: str) -> str`

- `normalize_plate`：`(plate or "").strip().upper()` —— 先 strip 再大写；空值返回空串（内部空格不自动清除，前端输入层负责）
- 所有入库前的车牌必须先 `normalize_plate` 再 `is_valid_plate`，保证"京a12345"与"京A12345"不会重复登记。

### 2.3 复用约定
李嘉诚的 `/parking/enter`、`/parking/exit` 和我的车辆接口都调这两个函数；谁改正则必须先跑 `test_pure_utils.py::TestPlateValidation` 四例确认全绿。

## 3. 第 2 周：车辆接口实现（routers/violation.py 前半）

1. `_role_of(db, user)`：取角色 code（复用陈硕的 `get_user_role_code`），列表过滤用；
2. `_vehicle_out(v)`：ORM → dict，**不带**任何用户敏感字段；
3. `_is_plate_valid(plate)`：内部封装 normalize + is_valid；
4. **`create_vehicle`**：normalize → 校验（20002）→ 查询未软删同车牌（20005）→ insert；`IntegrityError` 捕获后同样返回 20005（防并发穿透唯一索引）；
5. **`update_vehicle`**：改车牌时同样查重（排除自身 id）；改其他字段不动车牌；
6. **`delete_vehicle`（P0 修复点）**：
   - 车辆被删后，`plate_no` 写入 `*{id}` 墓碑，避免"删除后同车牌重新登记撞唯一索引 500"；
   - 关联违章保留（历史数据不可篡改），仅车辆软删；
7. 每个写操作都 `log_op`（create/update/delete_vehicle）。

验收脚本：登记 → 同车牌再登记得 20005 → 删除 → 同车牌重新登记成功（这正是 `test_delete_then_re_register_same_plate` 覆盖的场景）。

## 4. 第 3 周：违章状态机实现

1. **`create_violation`**：校验 `violation_type` 在字典内；`violation_time` 走 `to_local_naive()`（防前端 UTC 造成 8 小时偏差）；`evidence_url` 由上传接口（李嘉诚的 `/upload/image`）返回；默认 status=pending、audit_by/audit_time 为空；`log_op`；
2. **`audit_violation`**：status 必须是 pending（否则 20003）→ 按 result 置 confirmed/rejected → 写 `audit_by = 当前用户`、`audit_time = now()`、`audit_remark`；`log_op("audit_violation")`；
3. **`process_violation`**：status 必须是 confirmed（否则 20004）→ 置 processed；`log_op`；
4. **`list_violations`**：条件 status/type/keyword（车牌）；user 角色额外 `Vehicle.user_id == current_user.id` 过滤；时间倒序分页；返回 `_violation_out(v)`；
5. **`violation_stats`**：按类型分组计数 + 按状态分组计数 + 近 7 天总数，供仪表盘/大屏复用。

状态流转验收（与 demo.md 第 3 节一致）：
```
录入(闯红灯, 200/6) → pending → 通过 → confirmed → 标记已处理 → processed
                              ↘ 驳回 → rejected（不可处理）
```

## 5. 第 3 周：Excel 导出（services/excel_service.py、routers/export.py）

### 5.1 `build_xlsx(title, headers, rows) -> bytes`

- 第 1 行：`{标题}（导出时间：YYYY-MM-DD HH:MM:SS）`，合并单元格、加粗蓝色；
- 第 2 行：表头，填充 `#1F6FB2`、白色加粗、居中；
- 第 3 行起：数据，每个单元格过 `_safe_cell`；
- 自动列宽：按前 200 行采样，中文按 2 列宽估算，上限 42；
- `ws.freeze_panes = "A3"` 冻结标题+表头；
- 用 `BytesIO` 内存生成，返回 bytes，不落临时文件。

### 5.2 `_safe_cell(value)`（安全修复点）

若字符串以 `=`、`+`、`-`、`@`、`\t`、`\r` 开头，前置英文单引号 `'`，防止 Excel 公式注入（DDE）。审核备注、车牌等用户可控文本全部经过它。

### 5.3 `routers/export.py` 三个端点

| 端点 | 函数 | 数据源 | 表头示例 |
|---|---|---|---|
| GET /export/violations.xlsx | `export_violations(...)` | violation + intersection 联查 | 车牌号/违章类型/违章时间/地点/罚款/扣分/状态/审核人/备注 |
| GET /export/parking-records.xlsx | `export_parking_records(...)` | parking_record + lot | 车牌号/停车场/入场时间/出场时间/时长/费用/状态 |
| GET /export/traffic-report.xlsx | `export_traffic_report(...)` | road_section + traffic_flow 按天聚合 | 日期/路段/平均流率/平均车速/饱和度/拥堵等级 |

公共出口 `_xlsx_response(filename, title, headers, rows)`：`build_xlsx` → `StreamingResponse`，`Content-Disposition` 用 RFC 5987 编码中文文件名。

### 5.4 前端下载链路（api/download.ts）

`downloadFile(url, params, filename)`：走统一 http 实例（`responseType: 'blob'`）→ 401 也能跳登录 → `URL.createObjectURL` 触发下载后 `revokeObjectURL`；文件名用 `utils/datetime.ts` 的**本地时间**（不用 toISOString，否则日期会差 8 小时）。

## 9. 常见坑位与修复记录

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 1 | 删车后同车牌重登记 500 | plate_no 唯一索引 + 软删仍占位 | 墓碑后缀 `*{id}` + 查重 + IntegrityError 兜底（20005） |
| 2 | 导出文件日期差 8 小时 | 前端用 `toISOString()`（UTC） | 改名/筛选一律本地时间函数 |
| 3 | Excel 打开弹出"公式错误" | 备注含 `=` 开头 | `_safe_cell` 前置单引号 |
| 4 | Excel 中文文件名乱码 | Content-Disposition 未编码 | RFC 5987 `filename*=UTF-8''...` |
| 5 | 违章时间存成 UTC | 前端直传 ISO 字符串 | 后端 `to_local_naive()` 统一转换 |
